# 钣金工作流工具包

此工具包为 SOLIDWORKS 增加经过验证的连接器级钣金板件和面板创建、编辑工作流。设计重点是明确尺寸语义、使用原生钣金特征，并在每次修改后读取 SOLIDWORKS 的实际结果。

## 设计目标

- 使用 SOLIDWORKS 原生钣金特征，而不是用普通实体近似折弯。
- 每次创建都必须明确板厚、内折弯半径和尺寸模式。
- 文档创建与保存、PDM、覆盖、删除及导出保持分离。
- 编辑已有生产零件前先检查其状态。
- 拒绝过期令牌、含糊拓扑、重建错误和参数读回不符。
- 将展开图抑制、展开/折叠特征和特征树回滚视为不同操作。

## 配置与模板

内置配置名为 `standard_2026`，用于解析标记为 `2026 plaat` 的零件模板。

可将 `SW_MCP_SHEETMETAL_TEMPLATE` 设为准确的 `.prtdot` 路径，或通过 `SW_MCP_TEMPLATE_DIR` 指定包含模板的目录。若无法解析模板，创建操作会在打开新文档前停止。

配置包含首选基准面、原点约定、由模板控制的折弯补偿、释放槽默认值及 DXF 折弯线默认值。板厚和内折弯半径始终由任务明确提供。

## 尺寸模式

每个板件或面板请求必须选择：

- `flat_blank`：宽度和高度表示初始矩形展开料。
- `finished_outer`：宽度和高度表示折弯后的外包尺寸。

连接器不会自动猜测尺寸含义。

## 主要工作流工具

| 工具 | 用途 |
| --- | --- |
| `list_sheet_metal_profiles` | 报告可用配置、模板解析状态和默认设置。 |
| `create_sheet_metal_plate` | 按明确尺寸、板厚、半径和尺寸模式创建未保存的矩形基体法兰。 |
| `create_sheet_metal_panel` | 创建未保存板件，并按语义边添加法兰、褶边、角和释放槽。 |
| `inspect_sheet_metal_part` | 读取文档、配置、钣金参数、特征状态、实体、边界框、重建问题、持久拓扑引用和编辑令牌。 |
| `inspect_sheet_metal_edit` | 为受保护的参数编辑准备准确令牌和原生特征标识。 |
| `verify_sheet_metal_part` | 核对尺寸、板厚、半径、实体数、体积合理性、特征状态和重建状态。 |
| `inspect_sketch_alignment` | 列出兼容的直线草图段与模型边，包括方向、间隙、关系和持久引用。 |
| `set_sketch_line_collinear_to_edge` | 使用已检查的引用添加原生共线关系，恢复特征树状态、重建并验证。 |

## 原生制造操作

连接器提供基体法兰和边线法兰参数编辑，以及褶边、转折、草图折弯、撕裂、法向切除、闭合角、折断角和角释放。原生展开/折叠支持明确固定面，并可选择指定折弯或 `all_bends`。

每个应用操作都会重新读取创建或编辑后的原生特征定义。仅 COM 返回成功并不足以判定操作成功。

## 检查、应用、验证

编辑已有保存零件时：

1. 检查活动文档和目标特征。
2. 保留返回的编辑令牌与持久特征/拓扑引用。
3. 将这些准确值提交给应用工具。
4. 重建并验证原生特征定义、边界框、体积合理性和错误状态。
5. 由调用者审核后，再通过独立流程保存。

令牌绑定文档标识、活动配置、特征更新时间戳、持久引用、特征状态和边界框。任何中间改动都会使令牌过期。

## 面板边声明

面板特征使用 `left`、`right`、`bottom` 和 `top` 等语义边，而不是要求调用者保存临时边索引。每次几何变化后，工作流都会重新解析拓扑。

## 回滚与草图对齐

草图对齐只将回滚杆移动到使草图和模型边可用的位置，完成后恢复请求的特征树状态。如果 SOLIDWORKS 拒绝直接共线关系，连接器会停止，不会静默创建转换的构造几何。

## 展开图、展开/折叠和 DXF

- 展开图抑制用于改变生成的展开图特征状态。
- 展开/折叠围绕指定固定面创建原生制造特征。
- 回滚用于改变当前活动的特征树历史位置。
- DXF 导出是独立操作：会验证输出实体段，并在含折弯且请求折弯线时检查折弯图层实体。

## 安全边界

创建工具让新文档保持未保存状态。编辑工具不会保存、覆盖、删除、关闭或导出生产文档。PDM 命名、元数据弹窗、重复文件清理和库操作不属于此工具包。

## 验证

离线测试覆盖工具结构、无效尺寸、过期令牌、含糊选择、原生读回失败和模拟 COM 行为。实机回归仅在新建的一次性零件中执行，并在完成后恢复原始 SOLIDWORKS 会话。

当前已通过实机验证的范围包括两种尺寸模式、基体/边线法兰、褶边、法向切除、折断角、草图折弯、选择性及全部折弯展开/折叠、回滚、草图边共线、参数编辑和 DXF 验证。转折、撕裂、角释放和闭合角已有离线覆盖，其专用实机回归仍属于后续工作。
